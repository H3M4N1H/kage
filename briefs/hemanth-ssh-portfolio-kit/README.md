# Hemanth SSH Portfolio Kit

A secure, read-only SSH terminal portfolio handoff kit.

## Included
- `SKILL.md` — reusable build and security skill.
- `MASTER_PROMPT.md` — one-shot Codex implementation prompt.
- `PORTFOLIO_DATA.md` — profile and project content.
- `ARCHITECTURE.md` — architecture, hosting, and deployment notes.

## Usage
1. Open the SSH portfolio repository in Codex.
2. Copy these files into the repository root.
3. Paste the complete `MASTER_PROMPT.md` into Codex.
4. Ask it to implement and test locally.
5. Review security controls and content before deployment.

## Important
This kit deliberately specifies a custom SSH TUI application, not a shared shell account. Do not expose an OS shell to anonymous visitors. Hosting and deployment are not performed by this kit.
